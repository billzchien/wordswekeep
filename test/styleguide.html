Base colors

Used on the main screen and the menu. Components never use these directly; they use --bg and --fg, which default to paper and ink.

Category palettes

Notes mode takes the palette of the quote’s first category, in this order. Each palette is one background and one foreground.

Families

Five families, each with one job.

Quote scale

Fewer words, bigger type. A quote’s length picks its tier; each tier has a size for the main screen and one for notes mode, per breakpoint (desktop ≥ 1024, tablet 600–1023, mobile < 600). Desktop sizes hold the Figma value up to 1440px wide, then grow with the window to 1.5× at 2160px; the spacing around the type grows by the same factor. The highlighted column is the one you’re viewing. A CJK character counts as four, and CJK runs at 80% of the tier size.

Text

Original language

Shown when a quote has an original-language version. Upright rather than italic, with looser leading; it follows the same quote tiers.
